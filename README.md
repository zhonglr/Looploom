# Looploom

Looploom is a pnpm workspace.

## Workspace layout

- `apps/frontend-editor` — the frontend editor application
- `packages` — shared workspace packages

## Commands

Run these commands from the repository root:

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm preview
```
